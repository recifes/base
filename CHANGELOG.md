# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Semantic Versioning](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2025-12-09

### Adicionado
- Estrutura inicial do repositório Base HSN
- Sistema de versionamento para assets
- Suporte para Argon Dashboard v1.0.0
- Estrutura para Material UI (futuro)
- Estrutura para Tailwind Components (futuro)
- Documentação completa em README.md
- Licença MIT
- Templates MVP Padrão
- Scripts de automação e deploy
- Utilitários PHP e JavaScript comuns
- Guia de integração com Formi Zimbros

### Estrutura
- `/argon/versions/v1.0.0` - Primeira versão versionada do Argon
- `/templates` - Templates prontos para uso
- `/scripts` - Scripts de automação
- `/utils` - Utilitários compartilhados

## Tipos de Mudanças

- **Adicionado** - Para novas funcionalidades
- **Modificado** - Para mudanças em funcionalidades existentes
- **Descontinuado** - Para funcionalidades que serão removidas
- **Removido** - Para funcionalidades removidas
- **Corrigido** - Para correção de bugs
- **Segurança** - Para vulnerabilidades corrigidas
