# Argon Dashboard v1.0.0

## Versão Inicial

Esta é a versão inicial do Argon Dashboard no ecossistema HSN.

### Assets Incluídos

#### CSS
- `argon-dashboard.css` - Estilos principais
- `argon-dashboard.min.css` - Versão minificada
- `argon-dashboard.css.map` - Source map
- `nucleo-icons.css` - Ícones Nucleo
- `nucleo-svg.css` - Ícones SVG

#### JavaScript Core
- `bootstrap.bundle.min.js` - Bootstrap completo
- `bootstrap.min.js` - Bootstrap sem Popper
- `popper.min.js` - Popper.js standalone

#### JavaScript Plugins
- `bootstrap-notify.js` - Sistema de notificações
- `Chart.extension.js` - Extensões para Chart.js
- `chartjs.min.js` - Chart.js
- `perfect-scrollbar.min.js` - Scrollbar customizado
- `smooth-scrollbar.min.js` - Smooth scroll

#### JavaScript Principal
- `argon-dashboard.js` - Scripts principais
- `argon-dashboard.min.js` - Versão minificada
- `argon-dashboard.js.map` - Source map

### Como Usar

```html
<!-- Usando versão específica -->
<link rel="stylesheet" href="https://base.hsn.com.br/argon/versions/v1.0.0/css/argon-dashboard.min.css">
<script src="https://base.hsn.com.br/argon/versions/v1.0.0/js/argon-dashboard.min.js"></script>

<!-- Usando versão latest (sempre a mais recente) -->
<link rel="stylesheet" href="https://base.hsn.com.br/argon/latest/css/argon-dashboard.min.css">
<script src="https://base.hsn.com.br/argon/latest/js/argon-dashboard.min.js"></script>
```
